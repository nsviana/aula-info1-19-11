Meu primeiro site com duas páginas

Construa um pequeno site sobre um tema sorteado, utilizando HTML e links para navegar entre duas páginas.

1. Objetivo

Você desenvolverá um site simples, composto por duas páginas HTML, sobre um tema definido por sorteio. O visitante deverá conseguir acessar a segunda página a partir da primeira e também retornar à página inicial.

A atividade busca praticar a estrutura básica de documentos HTML, a organização do conteúdo e a criação de links entre arquivos do mesmo projeto.

2. Regras de desenvolvimento

  • Crie exatamente dois arquivos HTML: index.html e detalhes.html.
  • É proibido utilizar os atributos id e class e o elemento <div> nas páginas criadas pelos alunos.
  • Use elementos HTML apropriados para organizar o conteúdo, como <header>, <nav>, <main>, <section>, <article> e <footer>.
  • Utilize títulos, parágrafos, listas, imagens e links, de acordo com as exigências abaixo.
  • A navegação deve ser feita com a tag <a> e o atributo href, sem JavaScript.
  • Não utilize bibliotecas, frameworks ou código gerado por IA. O foco é praticar HTML manualmente.
Sobre aparência: não é obrigatório aplicar CSS nesta atividade. A prioridade é ter uma estrutura HTML correta, conteúdo organizado e navegação funcional.

3. O que construir em cada página?

Página 1 — index.html

Será a página inicial do site. Inclua:

  • Nome do site e título principal com <h1>;
  • Apresentação do tema em pelo menos dois parágrafos;
  • Uma imagem relacionada ao tema, com atributo alt;
  • Uma lista com pelo menos três itens;
  • Um link para detalhes.html.

Página 2 — detalhes.html

Será uma página de aprofundamento. Inclua:

  • Título principal com <h1>;
  • Dois subtópicos com <h2>;
  • Texto explicativo em cada subtópico;
  • Uma lista ordenada com pelo menos três itens;
  • Um link para retornar a index.html.

As duas páginas devem conter a estrutura básica do HTML: <!DOCTYPE html>, <html>, <head>, <title> e <body>. Defina também o idioma da página e a codificação UTF-8.

4. Como usar o PlayCode — passo a passo

Utilize o editor disponível em https://playcode.io/html-template.

  1. Abra o PlayCode: acesse o endereço acima e entre no editor HTML do projeto, sem recorrer à geração por IA.
  2. Prepare a página inicial: localize o arquivo index.html na lista de arquivos e substitua o conteúdo de exemplo pelo código da sua página inicial.
  3. Crie a segunda página: na área de arquivos, use a opção de adicionar/criar arquivo (geralmente representada por + ou New File) e nomeie-o detalhes.html.
  4. Escreva o conteúdo: edite o HTML de detalhes.html. Cada arquivo precisa ter seu próprio documento HTML completo.
  5. Configure a navegação: abra o menu do projeto, entre em Settings (Configurações) e, na seção General → Behavior, deixe a opção SPA mode desativada. Essa opção permite navegar entre arquivos HTML diferentes.
  6. Crie os links: em index.html, use href="detalhes.html"; em detalhes.html, use href="index.html".
  7. Teste: utilize a visualização do site (Preview), clique no link para a segunda página e depois no link de volta. Verifique se o conteúdo muda corretamente.
Atenção: os nomes dos arquivos precisam corresponder exatamente aos nomes usados nos links. Por exemplo, detalhes.html é diferente de detalhe.html. Mantenha os dois arquivos na mesma pasta.

A interface do PlayCode pode mudar. Se algum botão tiver outro nome, procure a função equivalente de criar arquivo ou abrir configurações. Consulte também a orientação sobre o modo SPA.

5. Exemplo mínimo de navegação

A estrutura esperada no projeto é:

meu-site/
├── index.html
└── detalhes.html

No arquivo index.html, inclua um link que leve à segunda página:

<nav>
  <a href="detalhes.html">Conhecer mais sobre o tema</a>
</nav>

No arquivo detalhes.html, inclua um link de retorno:

<nav>
  <a href="index.html">Voltar à página inicial</a>
</nav>
Importante: os exemplos mostram somente os links. Você precisará criar toda a estrutura e os conteúdos das duas páginas por conta própria.

6. Temas para sorteio

Cada aluno desenvolverá seu site com base no tema sorteado. Você pode escolher os textos, imagens e subtópicos que façam sentido para o assunto.

  1. Turismo local — pontos turísticos e passeios.
  2. Animais de estimação — cuidados e curiosidades.
  3. Jogos digitais — gêneros e jogos favoritos.
  4. Alimentação saudável — hábitos e sugestões.
  5. Esportes — modalidades e benefícios.
  6. Música — estilos e artistas.
  7. Cinema — gêneros e filmes.
  8. Meio ambiente — preservação e atitudes sustentáveis.
  9. Tecnologia no cotidiano — dispositivos e aplicações.
  10. Livros e leitura — gêneros e recomendações.

7. Checklist antes de concluir

Antes de mostrar seu trabalho ao professor, confira:

  • Criei os arquivos index.html e detalhes.html.
  • As duas páginas possuem documento HTML completo e títulos adequados.
  • Incluí todos os textos, listas, imagem e subtópicos solicitados.
  • Consigo ir da primeira página para a segunda e voltar.
  • Não usei id, class nem <div>.
  • Conferi o resultado na visualização do PlayCode.

Apresentação: demonstre ao professor as duas páginas funcionando, incluindo a navegação de ida e volta. Siga as orientações de entrega informadas em sala.
